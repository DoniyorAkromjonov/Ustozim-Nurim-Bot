# Ustozim Quiz Bot на Python

Это версия Telegram бота на **aiogram 3**. Бот получает обновления через long polling, а прогресс хранит в локальной SQLite базе. Для запуска не нужны Cloudflare, Wrangler, webhook или отдельная настройка сервера.

## Быстрый запуск

Нужен Python 3.10 или новее.

1. Скопируйте `.env.example` в `.env`.
2. Впишите токен бота от BotFather и токен OpenRouter:

```env
BOT_TOKEN=токен_телеграм_бота
OPENROUTER_API_KEY=токен_openrouter
```

3. Откройте терминал в этой папке и выполните:

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
py main.py
```

На Linux/macOS команды активации такие:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Оставьте окно терминала открытым, пока бот работает. Остановить его можно через `Ctrl+C`. При первом запуске автоматически создастся файл `ustozim_quiz.db` с прогрессом пользователей.

## Возможности

- **Ежедневная викторина:** 15 вопросов на узбекском — IT (6), лидерство (3), религиозные знания (2), кино (2), логика (2). Вопросы генерируются через OpenRouter. Если AI недоступен, бот берёт вопросы из локальной базы.
- **Категории в отдельной кнопке:** смешанные вопросы, IT, математика, английский, логика, исламские знания и вопросы по книге. Пункт «Викторина» открывает ежедневный режим; его кнопка также остаётся в главном меню.
- **Тренировка в своём темпе:** вопросы из базы, по пять за подход, с сохранением позиции.
- **Книжный марафон:** 14 этапов по книге «Ta'limul muta'allim», прогресс по главам и результаты.
- **Статистика:** ответы, процент правильных ответов, streak и прогресс марафона.
- **Рейтинги:** в 22:00 в группу отправляются два отдельных сообщения: топ-10 завершивших ежедневную викторину (с кнопкой запуска бота), затем отдельный топ-5 по каждой активной категории. Учитываются участники минимум с пятью ответами, сортировка — по проценту правильных ответов.
- **Автоматические задачи по времени Ташкента:** в 21:00 объявление главы и личные напоминания, в 23:30 два отдельных рейтинговых сообщения в группе, в 23:30 рейтинг марафона в канале. Если бот был выключен в момент генерации, вопросы создадутся при первом обращении.
- **Команды администратора:** `/stats`, `/reset [user_id]`, `/sinov fasl`, `/sinov reyting`.

## Настройки

Для запуска нужны два токена. Чтобы получать групповые отчёты, укажите в `.env` числовой ID группы в `CHAT_ID` (обычно начинается с `-100`); пример ID ниже нужно заменить своим:

```env
# Shu ikki tokenni kiriting. AI token OpenRouter token bo'lishi kerak.
# Guruh hisobotlari uchun ID ni kiriting (masalan: -1001234567890).
CHAT_ID=-0000000000000
BOT_TOKEN=your_bot_token_here
OPENROUTER_API_KEY=your_openrouter_api_key_here

```

Для отчётов добавьте бота в группу и назначьте администратором, затем укажите её ID в `CHAT_ID`. Для публикаций марафона добавьте бота в канал с правом публикации. Для личных напоминаний пользователь должен хотя бы один раз открыть бота. Не публикуйте `.env`: в нём находятся секретные токены.

## Файлы

- `main.py` — логика бота и расписание задач.
- `quiz_bank.json`, `kitob_bank.json` — перенесённые базы вопросов.
- `.env` — токены и необязательные настройки.
- `ustozim_quiz.db` — локальные результаты пользователей.

Старая база пользователей из Cloudflare KV автоматически не переносится. Новая SQLite база начнёт собирать прогресс с нуля; файлы вопросов перенесены.
